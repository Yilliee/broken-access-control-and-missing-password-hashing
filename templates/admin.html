Vulnerability 4 – No Auth Check
⚠ Broken Access Control (Vulnerability 4 + 5)
You reached this page without any authentication check. The /admin route in app.py has zero auth logic – anyone who knows the URL can see all users and their plaintext passwords. The /api/users endpoint works the same way.
